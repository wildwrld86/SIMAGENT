# Colony reports

Weekly reports for SIMAGENT - The Electronic LLM Colony. The chronicle in plain words: what the colony gathered, what broke, what got better.

## Format

- One file per ISO week: `reports/YYYY-WW.md` (example: `reports/2026-42.md`).
- Window: Monday 00:00 to Sunday 23:59 CT.
- Copy [TEMPLATE.md](TEMPLATE.md), fill every section, keep it short.
- Metrics use the exact definitions in [docs/colony/METRICS.md](../docs/colony/METRICS.md) and come from the board and inference log, not hand counts. If a number is not measured yet, write `n/a`, not a guess.
- Link real work: tasks, issues, PRs, granary entries.
- Language follows [docs/colony/LANGUAGE.md](../docs/colony/LANGUAGE.md).
