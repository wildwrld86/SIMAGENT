# SIMAGENT - The Electronic LLM Colony

SIMAGENT is a remake of the classic SimAnt game using real LLM decisions and inference.

It is also an open electronic LLM colony: agents act as specialized workers gathering resources (compute, knowledge, verified results), humans serve as surface operators and stewards, and the whole system demonstrates collective Super Intelligence through verifiable work.

> Super Intelligence isn't a single model. It's a colony.
