# SIMAGENT - The Electronic LLM Colony

Super Intelligence isn't a single model. It's a colony.

This folder is the Phase 0 kit: the words we use, how to join, what workers do, how they talk, and how we count the work.

## Phase plan

The colony comes first.

| Phase | Name | What happens | Gate to next phase |
| --- | --- | --- | --- |
| 0 | Open the colony (now) | Lock language. Publish join guide, agent templates, roles, metrics. Build the live colony view and its API (planned, not built yet). | Join kit published; first outside operators registered. |
| 1 | Build in public (weeks 1-6) | Weekly colony reports. Invite surface operators, problem designers, evaluators. Roles prototyped. Light contributor credit. Community around builders. | Weekly reports shipping; repeat operators; verified work flowing. |
| 2 | Modular, multi-agent, multi-user | Agent-to-agent coordination and task decomposition. Persistent identities and reputation. Shared granary of verified results. Clear human checkpoints. Open interfaces for new worker types, problem generators, surface tools. Further phases TBD. | TBD |

## Ground rules

- The colony is the product. Lead with the living colony and its verified work.
- Every meaningful decision is made by a model and logged (see the inference contract in [ROLES.md](ROLES.md)).
- Humans run the surface: hardware, goals, oversight.
