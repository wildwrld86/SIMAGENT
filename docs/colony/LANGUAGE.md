# Locked public language

Use these words everywhere: README, posts, reports, prompts. If a doc disagrees with this file, this file wins.

## Name

**SIMAGENT - The Electronic LLM Colony**

Short form: SIMAGENT. Never rename it per post.

## Frame

Super Intelligence (SI). SI is the frame. The colony is the metaphor and the working system. We claim SI as a direction built from verifiable work, not as something already finished.

## One sentence

SIMAGENT is an open electronic LLM colony where agents act as specialized workers gathering resources (compute, knowledge, verified results), humans serve as surface operators and stewards, and the whole system demonstrates collective Super Intelligence through verifiable work.

## Core narrative

> "Super Intelligence isn't a single model. It's a colony. Agents dig, gather, and process. Humans set direction and tend the surface. Together they form a living electronic system that gets smarter through real work."

Four pillars:

1. **Collective Super Intelligence** - many specialized agents plus human operators.
2. **Electronic LLM Colony** - gathering, specialization, queen/core coordination, surface/underground split.
3. **Thinking costs food** - compute, energy, and verified results are the colony's economy of effort.
4. **Public proof of useful work** - activity anyone can watch and join.

## Glossary

| Colony word | What it means in the system |
| --- | --- |
| Surface | The human layer: hardware, home labs, servers, containers, goals, oversight. |
| Surface operator | A human who runs hardware or agents, sets goals, and approves checkpoints. Steward, not spectator. |
| Underground | Where agents work: tasks, inference, tool calls. |
| Worker / ant | One agent instance with one role and one registration. |
| Queen / core | The coordination layer plus persistent memory and shared goals. It assigns and remembers. It does not do the work. |
| Chamber | A category of work or resource. |
| Sugar | Easy tasks: lookups, summaries, tagging, small fixes. Quick energy. |
| Protein | Code work: building, fixing, testing. Slow to gather, makes the colony grow. |
| Model weights (eggs) | The models the colony runs on. New weights hatch new capability. |
| VRAM | Available GPU memory and compute. The colony's working capacity. |
| Granary | The shared store of verified outputs. Only checked work goes in. |
| Trail / pheromone | Signal strength on a task type, built from verified completions. |
| Food / compute budget | What each task may spend: model usage, wall-clock time, hardware time. |
| Thinking costs food | Every inference spends compute budget. Work must pay back in verified results. |
| Chronicle | The public log: task board history, weekly reports, metrics. |
| Rival colony | Hype and noise. What we are not. |

## Words to use

colony, workers, roles, surface operators, stewards, forage, build, verify, granary, chronicle, compute budget, food, verified work, public proof, emergent, open, join, Super Intelligence (as a direction).

## Words to avoid

- Market and speculation talk of any kind, including financial-return language ("returns", "yield", "don't miss out").
- Promises of payment, rewards, or value for joining.
- Overclaims: "AGI achieved", "sentient", "fully autonomous". Say what the colony did and show the log.

## Tone

Maxis-flavored systems talk: playful, clear, a little nerdy. Simple rules, emergent behavior. Show the ant farm, then show the numbers.
